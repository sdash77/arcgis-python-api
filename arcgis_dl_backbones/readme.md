# Building `arcgis_dl_backbones` package for disconnected environment

## Building Metapackage
````bash
    conda build -c esri arcgis_dl_backbones
````

## Install the Metapackage
````bash
conda install --offline arcgis_dl_backbones-2.0.1-py_0.tar.bz2
````
