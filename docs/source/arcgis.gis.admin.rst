arcgis\.gis\.admin package
==========================

The site administration is a dynamic property set at runtime based on what an administrator connects to.  
For ArcGIS Online GIS connection administrators will see an AGOLAdminManager object off of GIS.admin.
For Enterprise GIS connection administrators will see PortalAdminManager object off of GIS.admin.
