Contributing to Geosaurus (ArcGIS API for Python)
=================================================

Thank you for your interest in contributing to the Geosaurus project (ArcGIS API for Python).

Issues
------

Feel free to submit issues and enhancement requests.

Contributing
------------

Please refer to the [API Design Principles](https://github.com/arcgis/geosaurus/wiki#API_Design_Principles) for this project's style guidelines and guidelines for submitting patches and additions. In general, we follow the "fork-and-pull" Git workflow.

 1. **Fork** the repo on GitHub
 2. **Clone** the project to your own machine
 3. **Commit** changes to your own branch
 4. **Push** your work back up to your fork
 5. Submit a **Pull request** so that we can review your changes

NOTE: Be sure to merge the latest from "upstream" before making a pull request!

Identify areas from the “Sub-projects” section in the [wiki](https://github.com/ArcGIS/geosaurus/wiki) where you’d like to contribute, based on your interest and experience. Share this area with the group so everyone knows what others are working on and can help/collaborate, or pick another area for their own contributions. Multiple people can team up to work on an area as well. Coordinate and let everyone know. Mark your names on the wiki. Within Esri, we are using Slack for communicating - please see https://github.com/ArcGIS/geosaurus/wiki#Communication and join the Slack channel.
